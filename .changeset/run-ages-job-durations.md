The workflow view shows when each run started and how long ago that was, such as `Local · 14:02 · 5m ago` (with the date for runs from an earlier day), and GitHub runs show their age. Job cards and job rows show how long each finished job took, from its first matrix combination's start to its last one's end, and how long a running job has run so far.
