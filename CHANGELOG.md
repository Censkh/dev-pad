# Changelog

## Unreleased

Initial release planned as **0.1.0**. No release has been published yet.

### Added

- TypeScript service configuration and the `dev-pad`, `devpad`, and `dpad` CLI aliases.
- Node, Bun, and Deno support, with an OpenTUI renderer on Bun and a portable terminal UI on Node and Deno.
- Numbered service selection, scoped actions, and optional top-level service shortcuts.
- Start/restart, stop, URL opening, live status, health probes, and dependency ordering.
- Shared logs with scrolling, bounded history, and repeated spinner-frame suppression.
- Bun PTY input and process-group cleanup on POSIX.
- Runtime CI, Biome checks, lifecycle tests, and terminal interaction tests.
- A runnable example with two sites, an API, and an optional worker.
